# Glossário

| Termo | Significado |
|---|---|
| **C4 Model** | Notação de Simon Brown com 4 níveis de zoom: Contexto, Contêineres, Componentes, Código. |
| **Pessoa** | Usuário ou ator que interage com o sistema. |
| **Sistema de Software** | Algo que entrega valor; pode ser o sistema-alvo ou um sistema externo. |
| **Sistema externo** | Sistema fora da responsabilidade do time (em cinza nos diagramas). |
| **Contêiner (C4)** | Unidade implantável ou de armazenamento (web app, API, banco, app móvel). Não é só Docker. |
| **Componente** | Agrupamento de responsabilidades dentro de um contêiner. |
| **Diagrama dinâmico** | Colaboração entre elementos em um cenário (≈ sequência UML). |
| **Diagrama de implantação** | Mapeia contêineres para a infraestrutura real. |
| **ADR** | *Architecture Decision Record*: registra **por quê** de uma decisão. |
| **arc42** | Template de documentação: visões estruturais + decisões + cenários de qualidade. |
| **Documentação viva** | Diagramas como texto, versionados junto ao código. |
| **Mermaid / PlantUML / Structurizr** | Ferramentas de diagramas como código. |
